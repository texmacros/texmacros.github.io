## What's inside

| | |
|---|---|
| **Clock, date and weather** | Tashkent time, tap it for a month calendar. Weather from Open-Meteo |
| **Currency converter** | Pick any currency from the Central Bank of Uzbekistan and convert it to UZS |
| **10 languages** | English, Русский, Oʻzbekcha, Türkçe, Қазақша, 한국어, 中文, Español, Deutsch, Français |
| **Save contact** | One tap downloads a contact card (.vcf) |
| **Backgrounds and colors** | Bubbles, shapes, aurora, grid or plain, in purple, brown, teal or blue |

<br>

## Files

| File | What it is |
|---|---|
| `index.html` | The whole site: layout, styles and scripts in one file |
| `avatar.jpg` | Profile photo (optional, falls back to the GitHub avatar) |

<br>

## Run

Open `index.html` in a browser. No build step, no dependencies.

The site is served by GitHub Pages from the `main` branch, because the repository is named `texmacros.github.io`.
